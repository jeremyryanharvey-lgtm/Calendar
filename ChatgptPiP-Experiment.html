ChatgptPiP experiment

This is a proof of concept. It does not record the iPhone screen. A bookmarklet runs on the ChatGPT Safari page, reads visible conversation text, draws a simplified live view, and sends that generated video to Picture-in-Picture.

1. Create a Safari bookmarklet

  1. In Safari, bookmark any page.
  2. Open your bookmarks, tap Edit, and select that bookmark.
  3. Rename it ChatgptPiP.
  4. Replace its address with the code below, then save.

If Safari removes the “javascript:” part when saving, edit the bookmark again and add it back at the start. Safari may restrict bookmarklet execution depending on its version and settings.

2. Run it on ChatGPT

  1. Open your ChatGPT conversation in its Safari tab.
  2. Open the bookmarks menu and tap ChatgptPiP. A blue Start ChatgptPiP button should appear near the top-right of the ChatGPT page.
  3. Tap the blue Start ChatgptPiP button. This second tap is important because iPhone Safari requires a direct user gesture to start video PiP.
  4. Keep the ChatGPT tab open. New or changed message text should update the PiP view.

3. Stop it

Tap the blue PiP started · tap to stop button again to stop the preview, or close/reload the ChatGPT tab. If the button never appears after running the bookmarklet, the bookmarklet did not execute.

Known limitations: this is a text-and-layout approximation, not an exact screenshot. It may miss messages if ChatGPT changes its page structure, and iOS Safari may block bookmarklet-triggered video PiP. It is an experiment, not a guaranteed iPhone feature.
